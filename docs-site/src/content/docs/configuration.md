## Добавление Yandex Smart Home в Music Assistant

1. Откройте **Music Assistant → Настройки → Плагины**.
2. Нажмите **«+ Добавить»** и выберите **Yandex Smart Home**.
3. Следуйте инструкциям на экране для настройки провайдера.

## Параметры подключения

| Параметр | Значение |
|:---------|:---------|
| **Сервис** | [https://yandex.ru/dev/dialogs/smart-home/](https://yandex.ru/dev/dialogs/smart-home/) |
| **Метод аутентификации** | Yandex OAuth Token |
| **Макс. качество звука** | N/A (plugin — не предоставляет аудио) |

Подробное описание всех параметров смотрите в диалоге настройки провайдера в Music Assistant.
